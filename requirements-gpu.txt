# ============================================================
#  GPU INSTALL  --  use this on Colab or any CUDA machine
# ============================================================
#
#   pip install -r requirements-gpu.txt
#   python -c "import onnxruntime as o; print(o.get_available_providers())"
#     -> CUDAExecutionProvider must appear in that list
#
# torch is deliberately not listed. Colab ships it with CUDA already; on your
# own machine install the build matching your CUDA version from pytorch.org.
#
# TWO THINGS THAT WILL COST YOU THE GPU IF YOU SKIP THEM
#
# 1. Never install plain `onnxruntime` alongside this. Both wheels ship the
#    same onnxruntime/capi/*.so, so the second install overwrites the first
#    while pip still lists both -- you silently land on whichever came last,
#    the segmenter runs on CPU, and nvidia-smi shows ~0.2 GB used. This wheel
#    is a superset: it provides CPUExecutionProvider too. To recover:
#      pip uninstall -y onnxruntime onnxruntime-gpu
#      pip install -r requirements-gpu.txt
#
# 2. Point the segmenter at the FP32 model. INT8 dynamic quantization emits
#    ConvInteger/MatMulInteger ops the CUDA provider does not implement, so
#    the INT8 model falls back to CPU even with this wheel installed:
#      sed -i 's|segmenter: models/twinlitenet_int8.onnx|segmenter: models/twinlitenet_fp32.onnx|' config.yaml
#
# 3. The ORT version must match the host's CUDA MAJOR version. This is the
#    most common failure and it is not obvious, because ORT still LISTS
#    CUDAExecutionProvider and only fails when it tries to load the library:
#
#      Failed to load library libonnxruntime_providers_cuda.so with error:
#      libcublasLt.so.13: cannot open shared object file
#      Require cuDNN 9.* and CUDA 13.*
#
#    onnxruntime-gpu 1.23+ is built against CUDA 13. Colab currently ships
#    CUDA 12.x (check: torch reports 2.x+cu128), so it needs a CUDA 12 build.
#    1.22.0 is the last CUDA 12 release, which is why it is pinned below.
#
#    To check what your host has:
#      python -c "import torch; print(torch.version.cuda)"
#    CUDA 12.x -> onnxruntime-gpu==1.22.0 (pinned here)
#    CUDA 13.x -> onnxruntime-gpu>=1.23
#
#    If neither works, the segmenter falls back to CPU on its own and the run
#    still completes -- YOLO and CLIP keep using the GPU.

onnxruntime-gpu==1.22.0   # CUDA 12 build; see note 3 above before changing
